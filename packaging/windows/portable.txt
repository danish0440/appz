AppZ portable mode

While this file sits next to appz.exe, AppZ keeps its settings, its
download cache and its record of installed apps in the AppZData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move AppZ with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\AppZ) instead.
If AppZData can't be written (for example on a read-only drive), AppZ says
so and uses %APPDATA%\AppZ instead.
